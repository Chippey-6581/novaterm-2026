# novaterm-2026
A modernized fork of Novaterm, the Commodore 64 terminal program by Nick Rossi.  Optimized for the Ultimate - compatable with SwiftLink, UP9600 &amp; Wifi Modems

License

The original Novaterm source code was released freely to the C64 community by its author, Nick Rossi. It was not published under a formal open-source license.

This fork is shared in the same spirit: free for the community to use, study, and improve. Please keep the original author credits intact.
